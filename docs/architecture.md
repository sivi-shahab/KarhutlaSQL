# Diagram arsitektur

Diagram interaktif: klik komponen untuk detail, **PATH** menelusuri jalur
antar komponen, **LENS** menyorot satu jenis komponen, dan **Export**
mengunduh PNG/SVG. Buka [layar penuh](diagram/arsitektur.html).
